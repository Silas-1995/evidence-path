# Provenance

Evidence Path is an independently maintained derivative of
[PavedPath Code](https://github.com/Jia-Ethan/pavedpath-code), by Jia-Ethan,
reviewed at commit
[`97a319fcfd3f9b68976690e04f3b511d6171a300`](https://github.com/Jia-Ethan/pavedpath-code/tree/97a319fcfd3f9b68976690e04f3b511d6171a300).

The original local-problem → open-source evidence → minimal adaptation →
verification workflow informed this skill. The entrypoint and references have
been rewritten and reorganized. Evidence Path adds explicit search stopping
criteria, release/applicability checks, an optional report validator, and
validation fixtures. It is not an official successor or an endorsed release
of PavedPath Code.
